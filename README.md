# Bilan Locatif — simulateur d'investissement locatif

## 👉 [Ouvrir le simulateur](https://flavio051.github.io/Simulateur-invest-locatif/)

https://flavio051.github.io/Simulateur-invest-locatif/

Gratuit, sans compte : tout reste enregistré dans ton navigateur.

- **Importer une annonce** leboncoin, SeLoger, PAP, Bien'ici, Logic-Immo ou d'agence : prix (honoraires séparés), surface, DPE, charges, taxe foncière et photos. Avec le bouton ⚡ en 1 clic, ou par copier-coller. Tu vérifies chaque chiffre avant de valider.
- **Loyer d'équilibre** : le loyer à partir duquel le bien se paie tout seul.
- **Loyers du marché en 1 clic** : le bouton ⚡ sur une page de locations leboncoin donne la médiane du jour.
- **Verdict** : « se paie tout seul » ou effort mensuel, et le prix auquel il se paierait seul.
- **Préparer mon offre** : un message argumenté pour l'agent.
- **Comparer mes biens** : toutes tes simulations triées.
- **Partager** une simulation par lien, ou imprimer le dossier pour la banque.
- Fiscalité complète : LMNP réel ou micro-BIC, foncier, SCI à l'IS, Jeanbrun ; revente et plus-value.
